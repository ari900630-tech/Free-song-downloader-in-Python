# 🎵 הורדת מוזיקה ב-GitHub Actions

מערכת להורדת שירים מ-YouTube ישירות דרך השרתים של GitHub כקובצי MP3, ללא צורך בהתקנת תוכנות במחשב.

---

## 🚀 איך משתמשים? (בשני שלבים פשוטים)

### שלב 1: חיפוש השירים
1. היכנס ללשונית **Actions** למעלה.
2. תחת **Workflows** מצד שמאל, לחץ על **Music Downloader**.
3. לחץ על כפתור **Run workflow** מצד ימין.
4. הגדר את השדות:
   - **mode**: בחר `search`
   - **artist_name**: הקלד את שם הזמר או השיר (למשל: `חנן בן ארי`)
5. לחץ על **Run workflow** הירוק.
6. היכנס להרצה שהתחילה, לחץ על ה-Job בשם **run-script**, ופתח את השלב **Run Search or Download** כדי לראות את רשימת השירים המפורטת עם המספרים שלהם (למשל: `[1]`, `[2]`, `[3]`).

---

### שלב 2: הורדת השירים שנבחרו
1. חזור ללשונית **Actions** -> **Music Downloader** ולחץ שוב על **Run workflow**.
2. הגדר את השדות:
   - **mode**: בחר `download`
   - **artist_name**: הקלד את אותו שם זמר/שיר שחיפשת בשלב 1
   - **selection**: הקלד את מספרי השירים שברצונך להוריד:
     - `all` - להורדת כל השירים ברשימה
     - `1-5` - להורדת טווח שירים (מ-1 עד 5)
     - `1,3,6` - להורדת שירים ספציפיים
3. לחץ על **Run workflow** הירוק.
4. כשהתהליך מסתיים (מופיע V ירוק), היכנס להרצה ובתחתית העמוד (תחת **Artifacts**) תמצא קובץ ZIP מוכן להורדה עם כל השירים כקובצי MP3!
